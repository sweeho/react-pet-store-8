# Localization

## Why

Recover the locale-handling behaviour of the legacy storefront: session locale, language switching, locale-keyed screens and catalog text, request encoding, number formatting, localized email and per-locale data.

## What Changes

- Adds requirements for localization behaviour recovered from 24 reviewed IR records (several pass files restate the same rule).
- One screen requirement: the common page layout.

## Impact

Affects catalog, cart, order email, customer profile and the front controller.
